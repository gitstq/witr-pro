## 简介

Witr Pro (Why is this running? Pro Edition) 是一个功能强大的进程监控工具。

## 功能特性

- 进程搜索与查询
- 实时资源监控
- 进程树可视化
- 系统概览
- 查询历史记录
- 进程终止

## 快速开始

### 安装

```bash
pip install -r requirements.txt
```

### 使用

```bash
# 查看帮助
python3 witr_pro.py --help

# 查找进程
python3 witr_pro.py find python

# 系统概览
python3 witr_pro.py system

# 实时监控
python3 witr_pro.py watch
```
